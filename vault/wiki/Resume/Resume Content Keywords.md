# Resume Content Keywords

Optimization involves tailoring resume language to job descriptions and managing specific elements like GPA and awards.

## Details

- Look for repeated words in a target job description and try to repeat those in your resume bullets *(source: [[raw/Aug 2025 - Resume Only Workshop.pdf|Aug 2025 - Resume Only Workshop]])*
- Remove undergrad GPA because the moment it’s added it opens you up to comparison *(source: [[raw/Aug 2025 - Resume Only Workshop.pdf|Aug 2025 - Resume Only Workshop]])*
- Remove undergrad awards unless you have space *(source: [[raw/Aug 2025 - Resume Only Workshop.pdf|Aug 2025 - Resume Only Workshop]])*
- Use abbreviations only if you are moving within the same industry or function *(source: [[raw/Aug 2025 - Resume Only Workshop.pdf|Aug 2025 - Resume Only Workshop]])*
