# Resume Application Tips

Tips include being prepared to commit to specific dates, addressing long phrases, and using humor in an additional section.

## Details

- If the posting says “The successful candidate must commit to XYZ dates,” be ready to commit to these. Don’t ask for an exception *(source: [[raw/Aug 2025 - Resume Only Workshop.pdf|Aug 2025 - Resume Only Workshop]])*
- Really long phrases (bullets that are extra long or at a greater level of detail than the others) suggest this is a pain point in the company; network to confirm this is the case and emphasize the skills that can “fix” or combat this *(source: [[raw/Aug 2025 - Resume Only Workshop.pdf|Aug 2025 - Resume Only Workshop]])*
- Make sure you have an additional section and be humorous to entice the reader to ask you about it. The section should be 1-3 lines *(source: [[raw/Aug 2025 - Resume Only Workshop.pdf|Aug 2025 - Resume Only Workshop]])*
